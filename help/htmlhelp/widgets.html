🧩 Widgets

Componenti riutilizzabili per la creazione di form e input

📖 Descrizione

I Widgets sono componenti riutilizzabili per la creazione di form e input. Ogni widget rappresenta un tipo di campo di input con le sue specifiche caratteristiche.

Tutti i widget estendono wBase che fornisce funzionalità comuni come gestione del valore, validazione, gestione errori e callbacks.

🚀 Utilizzo Base

<template> <c-widget :conf="widgetConf"></c-widget> </template> <script> export default { data() { return { widgetConf: { name: 'email', type: 'w-input', label: 'Email', required: true, rules: ['required', 'email'] } } } } </script>

⚙️ Proprietà Comuni a Tutti i Widget

  • name: Nome del campo (obbligatorio)
  • type: Tipo di widget (es. 'w-input', 'w-select')
  • label: Etichetta del campo
  • value: Valore iniziale
  • required: Campo obbligatorio (true/false)
  • disabled: Campo disabilitato (true/false o funzione)
  • readonly: Campo in sola lettura
  • rules: Regole di validazione
  • layout: Configurazione layout (labelPosition, width, etc.)
  • change: Callback chiamata al cambio valore
  • ready: Callback chiamata quando il widget è pronto
  • clear: Callback chiamata al reset

💡 Esempi di Configurazione

Input Semplice

var widgetConf = { name: 'email', type: 'w-input', label: 'Email', required: true, rules: ['required', 'email'], layout: { labelPosition: 'top', width: '100%' }, change: function(value) { console.log('Email changed:', value); } }

Select con Opzioni

var widgetConf = { name: 'role', type: 'w-select', label: 'Ruolo', required: true, options: [ { value: 'admin', label: 'Amministratore' }, { value: 'user', label: 'Utente' }, { value: 'guest', label: 'Ospite' } ], value: 'user' }

Date Picker

var widgetConf = { name: 'birthdate', type: 'w-date-picker', label: 'Data di Nascita', required: true, dateFormat: 'dd/mm/yy', showIcon: true }

Upload File

var widgetConf = { name: 'document', type: 'w-upload-ajax', label: 'Documento', extensions: ['pdf', 'doc', 'docx'], maxFileSize: '5M', routeName: 'uploadfile', onSuccess(file) { console.log('File caricato:', file); } }

🔧 Widget Base (wBase)

Tutti i widget estendono wBase che fornisce funzionalità comuni:

  • Gestione del valore (getValue, setValue)
  • Validazione
  • Gestione errori
  • Callbacks (ready, change, clear)
  • Metodi sovrascrivibili

🔧 Metodi Principali dei Widget

  • getValue(): Ottiene il valore corrente
  • setValue(value): Imposta il valore
  • reset(): Ripristina il valore iniziale
  • clear(): Pulisce il campo
  • validate(): Valida il campo
  • getFieldName(): Ottiene il nome del campo per il form
  • disabled(event): Verifica se il campo è disabilitato

✅ Validazione

I widget supportano regole di validazione tramite la proprietà rules:

  • required: Campo obbligatorio
  • email: Formato email valido
  • min: Valore minimo
  • max: Valore massimo
  • minLength: Lunghezza minima
  • maxLength: Lunghezza massima
  • Regole personalizzate tramite funzioni

Esempio Validazione

var widgetConf = { name: 'password', type: 'w-input', label: 'Password', inputType: 'password', required: true, rules: [ 'required', { minLength: 8, message: 'La password deve essere di almeno 8 caratteri' }, { pattern: /[A-Z]/, message: 'La password deve contenere almeno una maiuscola' } ] }

🎨 Layout

La proprietà layout permette di personalizzare l'aspetto:

  • labelPosition: Posizione etichetta ('top', 'left', 'none')
  • width: Larghezza del campo
  • class: Classi CSS personalizzate
  • style: Stili inline

🎨 Widget Personalizzati

È possibile creare widget personalizzati utilizzando w-custom:

var customWidget = { name: 'myField', type: 'w-custom', component: 'MyCustomComponent', props: { // props da passare al componente customProp: 'value' } }

📝 Note

  • Tutti i widget estendono CrudComponent
  • I metodi possono essere sovrascritti tramite configurazione
  • Supportano binding bidirezionale con v-model
  • Integrazione completa con il sistema di validazione
  • Supportano template dinamici e rendering condizionale
  • Gestione automatica degli errori e messaggi di validazione
