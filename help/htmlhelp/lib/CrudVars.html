🌐 CrudVars

Variabili globali e configurazioni condivise

📖 Descrizione

CrudVars contiene configurazioni globali accessibili da tutti i componenti dell'applicazione.

⚙️ Proprietà

  • modelConfs: Configurazioni dei modelli
  • lang: Traduzioni e testi
  • icons: Configurazione icone
  • actionConfs: Configurazioni azioni
  • viewConfs: Configurazioni views
  • env: Variabili d'ambiente
  • useApi: Flag per uso API
  • validationMessages: Messaggi di validazione

💡 Esempi di Utilizzo

import CrudVars from '@cupparis-lib/lib/CrudVars'; // Accedere a configurazioni var modelConf = CrudVars.modelConfs['ModelUser']; var lang = CrudVars.lang; var icons = CrudVars.icons; // Modificare configurazioni CrudVars.modelConfs['MyModel'] = myModelConf; CrudVars.lang['app.custom'] = 'Testo personalizzato';
