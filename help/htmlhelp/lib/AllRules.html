✅ AllRules

Regole di validazione disponibili

📖 Descrizione

AllRules contiene tutte le regole di validazione disponibili per i widget, basate su VeeValidate.

📋 Regole Disponibili

required: Campo obbligatorio
email: Formato email valido
alpha: Solo lettere
alpha_dash: Lettere, numeri, trattini
alpha_num: Lettere e numeri
alpha_spaces: Lettere e spazi
between: Valore tra min e max
confirmed: Conferma campo
digits: Solo cifre
dimensions: Dimensioni immagine
ext: Estensione file
image: File immagine
integer: Numero intero
is: Valore uguale a
is_not: Valore diverso da
length: Lunghezza esatta
max: Lunghezza massima
max_value: Valore massimo
mimes: Tipo MIME file
min: Lunghezza minima
min_value: Valore minimo
not_one_of: Non in lista
numeric: Numero
one_of: In lista
regex: Espressione regolare
size: Dimensione file
url: URL valido

💡 Esempi di Utilizzo

import AllRules from '@cupparis-lib/lib/AllRules'; // Utilizzo nelle regole di validazione var widgetConf = { name: 'email', type: 'w-input', rules: [ AllRules.required, AllRules.email ] }; // Con parametri var widgetConf = { name: 'age', type: 'w-input', rules: [ AllRules.required, AllRules.min_value(18), AllRules.max_value(100) ] };
