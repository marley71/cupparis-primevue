📋 ProtocolList

Protocollo per gestione liste di record

📖 Descrizione

ProtocolList gestisce la formattazione e struttura delle risposte per liste di record, inclusa paginazione, ordinamento e filtri.

🔧 Proprietà

  • value: Array di record
  • metadata: Metadati dei campi e relazioni
  • pagination: Informazioni di paginazione (current_page, per_page, total, etc.)

🔧 Metodi

  • getData(): Ottiene tutti i dati del protocollo
  • jsonToData(json): Converte risposta JSON in dati del protocollo

💡 Esempio di Utilizzo

import ProtocolList from '@cupparis-lib/lib/ProtocolList'; var protocol = new ProtocolList(); protocol.jsonToData({ result: { data: [{ id: 1, name: 'Mario' }, { id: 2, name: 'Luigi' }], current_page: 1, per_page: 20, total: 2 }, metadata: { fields: { name: { options: [] } } } }); console.log(protocol.value); // Array di record console.log(protocol.pagination); // Info paginazione
