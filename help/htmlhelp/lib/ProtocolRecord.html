📄 ProtocolRecord

Protocollo per gestione singolo record

📖 Descrizione

ProtocolRecord gestisce la formattazione e struttura delle risposte per un singolo record, inclusi metadati e relazioni.

🔧 Proprietà

  • value: Oggetto record
  • metadata: Metadati dei campi e relazioni

🔧 Metodi

  • getData(): Ottiene tutti i dati del protocollo
  • jsonToData(json): Converte risposta JSON in dati del protocollo

💡 Esempio di Utilizzo

import ProtocolRecord from '@cupparis-lib/lib/ProtocolRecord'; var protocol = new ProtocolRecord(); protocol.jsonToData({ result: { id: 1, name: 'Mario', email: 'mario@example.com' }, metadata: { fields: { name: { options: [] } } } }); console.log(protocol.value); // Oggetto record
