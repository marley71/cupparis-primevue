🛣️ Route

Classe per la gestione delle route verso il server

📖 Descrizione

Route permette di costruire chiamate API in modo flessibile con parametri e valori dinamici nell'URL.

🔧 Metodi

  • getMethod(): Ottiene metodo HTTP
  • setMethod(m): Imposta metodo HTTP
  • getUrl(values): Ottiene URL completo con variabili valorizzate
  • setUrl(url): Imposta URL
  • setParam(key, value): Imposta parametro
  • setParams(params): Imposta più parametri
  • getParam(key): Ottiene parametro
  • setValues(values): Imposta valori per URL template
  • getConf(): Ottiene configurazione completa

💡 Esempi di Utilizzo

import Route from '@cupparis-lib/lib/Route'; import Server from '@cupparis-lib/lib/Server'; // Creare route con parametri nell'URL var route = new Route({ method: 'get', url: '/api/users/{id}', values: { id: 123 } }); // Eseguire chiamata Server.route(route, function(json) { console.log('Success:', json); }); // Route con parametri opzionali var route = new Route({ method: 'get', url: '/api/users/{id?}', values: { id: 123 } // Se id non è presente, viene rimosso dall'URL }); // Route con parametri POST var route = new Route({ method: 'post', url: '/api/users', params: { name: 'Mario', email: 'mario@example.com' } }); Server.route(route, function(json) { console.log('User created:', json); });
