📥 cImport

Componente per l'importazione di dati da file CSV o Excel

📖 Descrizione

cImport è il componente per l'importazione di dati da file CSV o Excel. Gestisce l'intero processo di importazione: caricamento file, validazione, anteprima e salvataggio.

Il componente supporta elaborazioni asincrone tramite job queue, progress tracking e gestione completa degli errori, rendendo l'importazione di grandi quantità di dati semplice e affidabile.

🚀 Utilizzo Base

<template> <c-import :conf="importConf"></c-import> </template> <script> import cupparisPrimevue from 'cupparis-primevue'; const cImport = cupparisPrimevue.cImport; export default { components: { cImport }, data() { return { importConf: { providerName: 'AnagraficaXls', title: 'Importazione Aziende', importDesc: 'Caricare un file Excel con le colonne: Ragione Sociale, CodFiscale, PIva' } } } } </script>

⚙️ Configurazione

Proprietà Obbligatorie

  • providerName Obbligatorio: Nome del provider di importazione (es. 'AnagraficaXls')

Proprietà Opzionali

  • title: Titolo da mostrare
  • sectionTitle: Titolo della sezione
  • importDesc: Descrizione testuale dell'importazione
  • importDescHtml: Nome file HTML per descrizione complessa
  • importFile: Nome modello da importare (default: nome modello)
  • viewUpload: Configurazione personalizzata per il form di upload
  • viewList: Configurazione personalizzata per l'anteprima dati
  • viewSave: Configurazione personalizzata per il salvataggio
  • confUpload: Configurazione personalizzata per il widget upload
  • ready: Funzione callback chiamata quando il componente è pronto

💡 Esempi di Configurazione

Configurazione Semplice

var conf = { providerName: 'AnagraficaXls', title: 'Importazione Aziende', importDesc: 'Caricare un file Excel con le colonne: Ragione Sociale, CodFiscale, PIva', viewUpload: { fields: ['resource'], fieldsConfig: { resource: { type: 'w-upload-ajax', extensions: ['xls', 'xlsx'], maxFileSize: '5M' } } } }

Configurazione Avanzata

var conf = { providerName: 'AnagraficaXls', title: 'Importazione Aziende', importDescHtml: 'headerImportAziende.html', importFile: 'ModelAzienda', viewUpload: { fields: ['resource', 'options'], fieldsConfig: { resource: { type: 'w-upload-ajax', extensions: ['xls', 'xlsx', 'csv'], maxFileSize: '10M', routeName: 'uploadfile' }, options: { type: 'w-checkbox', label: 'Sovrascrivi record esistenti', value: false } }, actions: ['action-save'] }, ready() { console.log('Componente import pronto'); } }

🔄 Processo di Importazione

Il componente gestisce 4 fasi principali:

1. Upload

Caricamento del file da importare. L'utente seleziona e carica il file CSV o Excel.

2. Loading

Elaborazione e validazione del file. Il componente mostra una progress bar durante l'elaborazione asincrona.

3. Tosave

Anteprima dei dati pronti per il salvataggio. L'utente può verificare i dati prima del salvataggio definitivo.

4. Saving

Salvataggio effettivo dei dati nel database. Il componente gestisce il processo di inserimento/aggiornamento.

📊 Stati del Componente

  • step: Fase corrente ('upload', 'loading', 'tosave', 'saving')
  • importStatus: Stato dell'importazione ('upload', 'load')
  • jobId: ID del job di elaborazione
  • progressEnabled: Mostra la barra di progresso
  • uploadEnabled: Abilita il caricamento file
  • saveEnabled: Abilita il salvataggio

📤 Configurazione Upload

La configurazione di default per l'upload supporta:

  • extensions: Estensioni file consentite (default: ['csv'])
  • maxFileSize: Dimensione massima file (default: '2M')
  • routeName: Nome route per l'upload (default: 'uploadfile')
  • onSuccess: Callback chiamata al successo dell'upload
  • onError: Callback chiamata in caso di errore

Esempio Configurazione Upload Personalizzata

viewUpload: { fields: ['resource'], fieldsConfig: { resource: { type: 'w-upload-ajax', extensions: ['xls', 'xlsx', 'csv'], maxFileSize: '10M', routeName: 'uploadfile', onSuccess(file) { console.log('File caricato:', file); this.importForm(); }, onError(error) { console.error('Errore upload:', error); } } } }

📄 Descrizione HTML Dinamica

È possibile utilizzare un file HTML per la descrizione dell'importazione. Il file deve essere posizionato nella cartella definita da VITE_PUBLISH_DIR.

var conf = { providerName: 'AnagraficaXls', importDescHtml: 'headerImportAziende.html' }

Il file HTML può contenere variabili template che vengono sostituite con i dati del componente. Ad esempio, {{title}} verrà sostituito con il valore di conf.title.

🔧 Metodi Principali

  • importForm(): Avvia il processo di importazione
  • checkStatus(): Controlla lo stato del job di elaborazione
  • reset(): Ripristina il componente allo stato iniziale
  • getImportDescHtml(): Carica la descrizione HTML

🌐 Routes Utilizzate

  • uploadfile: Upload del file
  • load_datafile: Caricamento e validazione dati
  • status_queue: Controllo stato job
  • save_datafile: Salvataggio dati nel database

⚠️ Gestione Errori

Il componente gestisce automaticamente gli errori durante le varie fasi:

  • Errori di upload: Mostrati immediatamente all'utente
  • Errori di validazione: Mostrati dopo il caricamento con dettagli specifici
  • Errori di salvataggio: Mostrati durante il salvataggio con possibilità di retry

📝 Note

  • Il componente utilizza un sistema di job queue per elaborazioni asincrone
  • Supporta progress bar per operazioni lunghe
  • Le configurazioni delle viste vengono create automaticamente se non specificate
  • Estende CrudComponent e fornisce tutte le funzionalità base
  • Supporta file CSV e Excel (xls, xlsx)
  • Gestione automatica della validazione dei dati
  • Possibilità di anteprima prima del salvataggio definitivo
