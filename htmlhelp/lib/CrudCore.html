🔧 CrudCore

Libreria principale con funzioni di utilità e helper

📖 Descrizione

CrudCore è la libreria principale che fornisce funzioni statiche di utilità utilizzate da tutti i componenti della libreria.

🔧 Metodi Principali

  • clone(obj): Clona un oggetto in modo profondo, preservando funzioni e oggetti Vue
  • translate(key, plural, params): Traduce una chiave di testo con supporto per plurali e parametri
  • alertSuccess(msg, time): Mostra messaggio di successo
  • alertError(msg, time): Mostra messaggio di errore
  • alertWarning(msg, time): Mostra messaggio di warning
  • alertInfo(msg, time): Mostra messaggio informativo
  • waitStart(msg): Mostra indicatore di attesa
  • waitEnd(): Nasconde indicatore di attesa
  • fetchHtml(file, callback, data): Carica file HTML con sostituzione variabili
  • createProtocol(type): Crea un protocollo (list o record)
  • setupApp(app): Configura l'app Vue con componenti, direttive e plugin

📝 Funzioni di Trasformazione Stringhe

  • sentenceCase(str): Converte in sentence case
  • camelCase(str): Converte in camelCase
  • snakeCase(str): Converte in snake_case
  • pascalCase(str): Converte in PascalCase
  • kebabCase(str): Converte in kebab-case
  • titleCase(str): Converte in Title Case
  • upperCase(str): Converte in UPPERCASE
  • lowerCase(str): Converte in lowercase
  • upperCaseFirst(str): Prima lettera maiuscola

💡 Esempi di Utilizzo

Clonazione Oggetti

import CrudCore from '@cupparis-lib/lib/CrudCore'; // Clonare oggetto var original = { name: 'Mario', age: 30 }; var cloned = CrudCore.clone(original); cloned.name = 'Luigi'; // original.name rimane 'Mario'

Traduzione

// Traduzione semplice var text = CrudCore.translate('app.save'); // Traduzione con parametri var text = CrudCore.translate('app.welcome', 0, ['Mario']); // Traduzione plurale var text = CrudCore.translate('app.items', 1); // plurale

Alert e Wait

// Alert CrudCore.alertSuccess('Operazione completata', 3000); CrudCore.alertError('Errore!', 3000); CrudCore.alertWarning('Attenzione!', 3000); CrudCore.alertInfo('Informazione', 3000); // Wait CrudCore.waitStart('Caricamento...'); // ... operazioni ... CrudCore.waitEnd();

Fetch HTML

CrudCore.fetchHtml('template.html', function(html) { console.log(html); }, { name: 'Mario', age: 30 });

Trasformazione Stringhe

CrudCore.camelCase('hello world'); // 'helloWorld' CrudCore.snakeCase('Hello World'); // 'hello_world' CrudCore.pascalCase('hello world'); // 'HelloWorld' CrudCore.kebabCase('Hello World'); // 'hello-world'

📝 Proprietà Globali

  • componentItems: Registro componenti Vue
  • useItems: Registro plugin Vue
  • directiveItems: Registro direttive Vue
  • globalProperties: Proprietà globali Vue
  • defaultAlertTime: Tempo default per alert (3000ms)
