🌐 Server

Gestione chiamate HTTP al server

📖 Descrizione

Server gestisce tutte le chiamate HTTP al server, inclusa la gestione degli header di autenticazione (Bearer Token, CSRF Token).

🔧 Metodi

  • getUrl(url): Ottiene URL completo con subdomain se necessario
  • getHeaders(): Ottiene headers HTTP con autenticazione
  • route(route, callback, errorCallback): Esegue chiamata route
  • get(url, params, callback, errorCallback): Esegue GET
  • post(url, params, callback, errorCallback): Esegue POST

💡 Esempi di Utilizzo

import Server from '@cupparis-lib/lib/Server'; import Route from '@cupparis-lib/lib/Route'; // GET request Server.get('/api/users', {}, function(json) { console.log('Success:', json); }, function(error) { console.error('Error:', error); }); // POST request Server.post('/api/users', { name: 'Mario' }, function(json) { console.log('User created:', json); }); // Usando Route var route = new Route({ method: 'get', url: '/api/users/{id}', values: { id: 123 } }); Server.route(route, function(json) { console.log('Success:', json); }, function(error) { console.error('Error:', error); });
