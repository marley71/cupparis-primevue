📚 Librerie Core (lib)

Funzionalità base utilizzate da tutti i componenti

📖 Descrizione

La cartella lib contiene le librerie core della cupparis-primevue. Queste librerie forniscono le funzionalità base utilizzate da tutti i componenti.

Le librerie sono progettate per essere modulari e riutilizzabili, fornendo un'API consistente per operazioni comuni come chiamate HTTP, gestione route, validazione e utilità generali.

📦 Librerie Disponibili

🔧 CrudCore

Libreria principale con funzioni di utilità e helper. Fornisce metodi per clonazione, traduzione, alert, wait e molto altro.

🌐 CrudVars

Variabili globali e configurazioni condivise. Contiene modelConfs, lang, icons, actionConfs e altre configurazioni globali.

🌐 Server

Gestione chiamate HTTP al server. Fornisce metodi per GET, POST e gestione degli header di autenticazione.

🛣️ Route

Classe per la gestione delle route verso il server. Permette di costruire chiamate API in modo flessibile con parametri e valori dinamici.

📋 ProtocolList

Protocollo per gestione liste di record. Gestisce paginazione, ordinamento, filtri e formattazione risposta per liste.

📄 ProtocolRecord

Protocollo per gestione singolo record. Gestisce chiave primaria, formattazione risposta e relazioni per record singoli.

🛠️ CrudHelpers

Funzioni helper aggiuntive. Fornisce utilità per formattazione, validazione e manipolazione dati.

✅ AllRules

Regole di validazione disponibili. Contiene tutte le regole standard e personalizzate per la validazione dei campi.

💡 Utilizzo Generale

Le librerie sono importabili da @cupparis-lib/lib/ o direttamente da cupparis-primevue:

// Importazione diretta import CrudCore from '@cupparis-lib/lib/CrudCore'; import Server from '@cupparis-lib/lib/Server'; import Route from '@cupparis-lib/lib/Route'; // Oppure da cupparis-primevue import cupparisPrimevue from 'cupparis-primevue'; const CrudCore = cupparisPrimevue.CrudCore; const Server = cupparisPrimevue.Server;

📝 Note

  • Le librerie sono progettate per essere indipendenti e riutilizzabili
  • CrudCore fornisce funzioni statiche di utilità
  • Server gestisce tutte le chiamate HTTP
  • Route permette di costruire chiamate API in modo flessibile
  • CrudVars mantiene lo stato globale dell'applicazione
  • I protocolli definiscono il formato delle risposte API
  • Tutte le librerie sono documentate in dettaglio nelle rispettive pagine
